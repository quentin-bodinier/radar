# Radar

A daily focus dashboard, generated by Claude Code. Static HTML; data refreshed by slash commands and an optional 8am scheduled task. Pulls from Google Calendar, Slack, Gmail, and (optionally) Notion. Commitments live locally in `state/commitments.json` with carryover memory — items get a "🔁 3d carried" badge when they slip.

## Reproducing this for yourself

See [ONBOARDING.md](ONBOARDING.md). Setup is one clone, one script, and a small `state/config.json` to fill in.

## Files

- `today.html` — the dashboard. Permanent static file; loads `state/data.js` at startup.
- `template.html` — frozen HTML/CSS/JS template. `today.html` is generated from this once and never rewritten.
- `skills/` — the four slash command definitions, symlinked into `~/.claude/commands/` by the installer.
- `scheduled-tasks/radar-daily-rebuild/` — the 8am daily rebuild config.
- `scripts/install.sh` — symlink installer. Idempotent.
- `state/config.json` — your per-user config (gitignored).
- `state/commitments.json` — your commitments, source of truth (gitignored).
- `state/focus.json` — your daily focus tasks (gitignored).
- `state/history/YYYY-MM-DD.json` — daily snapshots for diffing.

## Slash commands

- **`/radar`** — full rebuild. Reads `commitments.json`, bumps carryover counters, pulls fresh data from Calendar/Slack/Gmail (+ optional Notion), writes `state/data.js`. Refresh the browser to see updates.
- **`/radar-commit "task" [--due YYYY-MM-DD] [--priority urgent|warning|info] [--notion <url>]`** — add a commitment.
- **`/radar-focus "task"`** — add a one-day focus task (separate from commitments, surfaces in the Focus strip).
- **`/radar-act [optional hint]`** — pick the top open item; either draft a Slack/Gmail reply (always as a draft) or run a deep-work session on a commitment.

## Keyboard shortcuts (in the dashboard)

- **`N`** — add a focus task. Opens a modal; tasks appear in the "My focus today" card, count toward day progress, and carry over until checked off or removed. State lives in `localStorage['radar-user-focus-tasks']`.

## Scheduled task

`radar-daily-rebuild` runs `/radar` at 8am every weekday via the scheduled-tasks MCP. Registration is a one-time step — see [ONBOARDING.md](ONBOARDING.md) step 8.
