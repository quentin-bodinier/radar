# Radar

Quentin's daily focus dashboard, generated by Claude Code.

## Files

- `today.html` — the dashboard, regenerated each morning (and on demand)
- `template.html` — frozen HTML/CSS/JS template; `/radar` fills in dynamic content
- `team.html` — separate team view (legacy)
- `state/commitments.json` — persistent commitment tracker (carryover memory)
- `state/focus.json` — manually-added focus tasks
- `state/history/YYYY-MM-DD.json` — daily snapshot for diffing

## Slash commands (user-scoped, in `~/.claude/commands/`)

- `/radar` — full rebuild: pull Calendar/Slack/Gmail/Notion, diff carryover, regenerate today.html
- `/radar-focus "task description"` — add a focus task that surfaces at the top of the Focus strip
- `/radar-act` — interactive: pick an actionable item, draft a Slack/Gmail reply or Notion update, send after confirmation

## Scheduled task

`radar-daily-rebuild` runs `/radar` at 8am every weekday via the scheduled-tasks MCP.
